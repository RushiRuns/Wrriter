# Wrriter - Project Rules and Governance Directive

> Automatically discovered and loaded by Antigravity at the start of every session.

## Always Active Governance
Every Antigravity session operating on this repository is strictly bound by:
1. **ARCHITECTURE.md**: Structural law, process boundaries, layers, and the 25 Rejection Rules.
2. **SYSTEM.md**: Conventions, TypeScript strictness, feature shapes, and the NEVER DO list.
3. **DONE.md**: The mandatory Definition of Done checklist for closing any feature or task.
4. **UTILITIES.md**: The registry of reusable components, helpers, and stores. Consult BEFORE writing any new code.
5. **PERFORMANCE.md**: Performance budgets and non-negotiable speed targets.
6. **DEPENDENCIES.md**: Strict FOSS-only, zero-telemetry dependency policy.

## Session Protocol
- Every session strictly follows the session template in `SYSTEM.md` section 9.
- One session = one feature = one commit (`M<N>: <feature> - <one line>`).
- Update `CHANGELOG_INTERNAL.md` and `UTILITIES.md` before committing.
