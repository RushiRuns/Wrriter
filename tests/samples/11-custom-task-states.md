# Custom Task States

Standard tasks:
- [ ] Incomplete task item
- [x] Completed task item

Custom task states commonly used in Obsidian themes:
- [/] In-progress task item
- [-] Cancelled or dropped task
- [?] Question or pending clarification
- [!] Urgent or high priority
- [>] Rescheduled or forwarded task
- [<] Scheduled or deferred task
- [p] Paused task item
- [c] Checked alternative state

All state markers inside brackets must be preserved byte-for-byte.
